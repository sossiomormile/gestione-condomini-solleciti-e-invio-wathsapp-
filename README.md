# Gestione Condomini V2
- Selezione cartella `Condomini_APP` da Chrome/Edge desktop.
- Ricerca automatica del file Excel del condominio.
- Lettura diretta XLS/XLSX/XLSM.
- Singole mensilità selezionabili.
- Conguagli e spese straordinarie selezionabili.
- Crediti/compensazioni evidenziati in giallo e NON applicati automaticamente.
- Nuovo totale calcolato solo dopo la scelta manuale delle compensazioni.
- WhatsApp e stampa/PDF.

I file reali dei condomini restano sul dispositivo e non vanno caricati nel repository GitHub.
